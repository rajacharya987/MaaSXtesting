Frequently Asked

Answers to common questions

How does DataFinder ensure 99.4% email accuracy?

We run real-time DNS MX record lookups, disposable domain detection, and direct SMTP mailbox handshakes without sending test emails to guarantee zero spam triggers.

Can I run DataFinder on my local machine?

Yes! The system includes an automated 1-click launcher (./launcher.sh, launcher.bat, or launcher.ps1) that installs dependencies, provisions the local SQLite database, and serves everything on http://localhost:3000.

What happens when I run out of credits?

You can instantly upgrade your subscription inside the dashboard or top up credits with one click without losing any saved leads or configured API keys.

Quick Start Integration Example

Query leads by industry or keywords directly using cURL or Node.js:

# 1. cURL Example
curl -X GET "http://localhost:3000/api/leads?industry=Cybersecurity" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json"

# 2. Node.js / Fetch Example
const response = await fetch('http://localhost:3000/api/leads', {
  headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' }
});
const data = await response.json();
console.log(data.leads);
